# Budget Recipe Finder

A Flutter mobile application that helps users discover recipes filtered by their personal meal budget. Built with Firebase Authentication and Cloud Firestore as the backend.

---

## Features

- User registration and login via Firebase Authentication
- Set and update a personal meal budget
- Browse recipes filtered dynamically by budget using a slider
- View full recipe details including ingredients, instructions, and cost breakdown
- Save recipes and manage meal plans from a personal profile

---

## Project Structure

```
lib/
├── model/
│   ├── recipe_model.dart       # Data class mapping tbl_recipes Firestore documents
│   └── user_model.dart         # Data class mapping tbl_users Firestore documents
│
├── screens/
│   ├── home.dart               # Main dashboard — hosts the budget slider and recipe feed
│   ├── login.dart              # Email/password sign-in page
│   ├── register.dart           # New user sign-up and initial budget setup
│   ├── profile.dart            # Account settings, budget update, and sign-out
│   ├── recipelist.dart         # Scrollable/grid layout rendering multiple recipe cards
│   ├── recipedetails.dart      # Full-page view for a single recipe
│   ├── recipe_card.dart        # Reusable card widget (image, title, price)
│   └── budget_slider.dart      # Standalone slider widget for adjusting price filter
│
├── services/
│   ├── auth_service.dart       # Firebase Authentication — login, register, logout
│   └── database.dart           # Firestore queries — fetch/filter recipes, update user data
│
├── firebase_options.dart       # Auto-generated Firebase project configuration
└── mainscaffhold.dart          # Root scaffold with BottomNavigationBar, manages screen switching
```

## Firestore Collections

| Collection    | Key Fields                                                          |
|---------------|---------------------------------------------------------------------|
| `tbl_recipes` | `recipeId`, `title`, `costEstimate`, `ingredients`, `instructions` |
| `tbl_users`   | `userId`, `globalBudget`, `savedRecipes`, `mealPlans`              |

## Getting Started

### Prerequisites

- Flutter SDK `^3.10.7`
- A Firebase project with Authentication (Email/Password) and Firestore enabled
- `google-services.json` (Android) placed in `android/app/`

### Install dependencies

```bash
flutter pub get
```

### Run the app

```bash
flutter run
```

## Notes

- `mainscaffhold.dart` contains a minor typo in its filename (`scaffhold` instead of `scaffold`). It is intentional for now — rename to `main_scaffold.dart` when cleaning up before release.
- `firebase_options.dart` is auto-generated by the FlutterFire CLI and should not be edited manually.
- all ID formats are year-number (except for tbl_savedrecipes). Ex: 2026001 (001 as the first user then 2026 is the current year)
